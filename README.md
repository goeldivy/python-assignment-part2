# Python Assignment Part 2

## Restaurant Order Management System

### 📌 Project Description

This project is a Python-based Restaurant Order Management System that simulates real-world restaurant operations. It allows users to view menus, place orders, manage inventory, and analyze sales data efficiently.

---

### 🚀 Features

* 📋 Menu display categorized (Starters, Mains, Desserts)
* 🛒 Order creation with validation (available/unavailable items)
* 💰 Automatic bill calculation with GST
* 📦 Inventory management using Deep Copy
* ⚠️ Low stock detection system
* 📊 Sales analysis and reporting (Top order, Total sales)

---

### 🧠 Concepts Used

* Python Dictionaries & Lists
* Loops and Conditional Statements
* Functions
* Deep Copy (`copy` module)
* String Formatting (f-strings)
* Basic Data Processing

---

### ▶️ How to Run

1. Open the project folder
2. Run the Python file:

```bash
python part2_order_system.py
```

---

### 📈 Output

The program displays:

* Menu with availability
* Order summary with total bill
* Inventory updates
* Sales report
